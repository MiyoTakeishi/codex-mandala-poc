# マンダラチャート共有アプリ 要件定義書

## 1. 目的

社内や趣味のグループで、マンダラチャートを作成・共有・編集できるWebアプリを提供する。
初期リリースではグループ登録機能は設けず、チャート単位の招待リンクを起点に閲覧・編集権限を扱う。

## 2. 想定ユーザー

- チャート作成者
  - Googleアカウントでログインし、マンダラチャートを作成する。
  - 自分が作成したチャートを一覧画面から開く。
  - 自分が作成したチャートのタイトルを編集する。
  - 個人利用として、招待リンクを発行せずに自分だけでチャートを閲覧・編集できる。
  - チャート招待リンクを発行し、共有する。
  - 編集を許可するメールアドレスを追加・削除する。
  - 自分が作成したチャートを削除する。
- チャート編集者
  - チャート作成者に許可されたメールアドレスのGoogleアカウントでログインしたユーザー。
  - 招待リンクからチャートを開き、編集アクション時に権限確認を受ける。
  - 権限確認後、対象チャートを編集する。
- ゲスト閲覧者
  - 招待リンクからマンダラチャートを閲覧するユーザー。
  - ログイン状態にかかわらず、招待リンクの初期アクセス時はゲスト扱いとする。
  - 編集はできない。

## 5. 用語定義

- マンダラチャート
  - 中央のテーマを起点に、周囲8マスへ要素を展開し、さらに各要素を中心とした9マスへ展開する思考整理フレーム。
- チャート
  - アプリ内で作成・保存される1つのマンダラチャート。
- チャート作成者
  - チャートを作成したログイン済みユーザー。
- チャート編集者
  - チャート作成者から編集を許可されたメールアドレスのGoogleアカウントでログインしたユーザー。
- 招待リンク
  - チャートへアクセスするための共有URL。
  - 招待リンクを知っているユーザーは、ログイン状態にかかわらず初期アクセス時にゲスト閲覧できる。

## 6. 機能要件

### 6.1 認証

- ユーザーはGoogleアカウントでログインできる。
- ユーザーはログアウトできる。
- 初回Googleログイン時に、アプリ内ユーザー情報を作成する。
- ユーザー情報として、Googleアカウント由来のメールアドレス、表示名、プロフィール画像を利用できる。
- 未ログインユーザーは、チャート作成、チャート一覧、編集操作など認証が必要な機能を利用できない。
- Googleログインに失敗した場合、ログインに失敗した旨と再試行導線を表示する。
- 初期リリースでは、メールアドレス・パスワード認証とパスワード再設定は実装しない。

### 6.2 チャート管理

- ログイン済みユーザーのみマンダラチャートを作成できる。
- チャートにはタイトル、作成者、作成日時、更新日時を持たせる。
- チャート作成者は、作成後にチャートタイトルを編集できる。
- チャートタイトル編集内容は保存できる。
- チャート一覧には、自分が作成したチャートのみを表示する。
- チャート一覧からチャートを開けるのは、チャート作成者のみとする。
- チャート作成者は、招待リンクを発行する前でも一覧画面から自分のチャートを閲覧・編集できる。
- チャート編集者とゲスト閲覧者は、チャート一覧から対象チャートを開けない。
- チャート編集者とゲスト閲覧者は、招待リンクから対象チャートを開く。
- 初期リリースでは、1ユーザーが作成できるチャート数は最大5個とする。
- 上限値は将来的に増やせる設計とする。
- チャート作成時に、9x9分の81セルを初期作成する。
- 81セルの初期作成に時間がかかる場合は、ローディング表示を行う。
- チャート作成者は、自分が作成したチャートを削除できる。
- チャート削除時は確認ダイアログを表示する。
- チャート削除は論理削除とし、データを即時に物理削除せず削除済み状態として扱う。
- 削除されたチャートは、一覧画面および招待リンクから閲覧できない。
- 初期リリースでは、チャート検索は対象外とする。

### 6.3 招待リンク

- チャート作成者は、チャート単位で招待リンクを発行できる。
- チャート編集者とゲスト閲覧者のアクセスは、すべて招待リンクを起点とする。
- 招待リンクを知っているユーザーは、ログインせずに対象チャートを閲覧できる。
- ログイン済みユーザーが招待リンクからアクセスした場合も、初期状態ではゲスト閲覧として扱う。
- 招待リンクにはパスワードを設定しない。
- 招待リンクの有効期限、無効化、再発行は初期リリースでは考慮しない。
- 招待リンクは推測困難なトークンを使用する。
- 招待リンクを知っていれば誰でも閲覧できるため、初期リリースでは機密性の高い情報を入力しない前提とする。
- 招待リンクをコピーできる。
- 招待リンクのコピーに成功した場合、コピー済みであることを表示する。
- 招待リンクが未発行の場合は、未発行状態を表示する。
- 招待リンク発行後は、発行済み状態を表示する。

### 6.4 編集権限管理

- チャート作成者は、チャート単位で編集を許可するメールアドレスを登録できる。
- 1チャートあたりの編集者数は最大10名程度とする。
- チャート作成者は、登録済みの編集者を削除できる。
- 編集者として許可されたメールアドレスのGoogleアカウントでログインしたユーザーのみ、対象チャートを編集できる。
- 編集アクションを行うまでは、招待リンク経由のアクセスはゲスト閲覧として扱う。
- ゲスト閲覧者が編集アクションを行おうとした場合、Googleログインを求める。
- ログイン後、ログイン中ユーザーのメールアドレスが編集許可済みであれば編集を開始できる。
- ログイン後、編集権限がない場合は編集できない旨を表示する。
- 許可メールアドレスとログイン中Googleアカウントのメールアドレスが一致しない場合、一致するGoogleアカウントでログインする必要がある旨を表示する。
- 初期リリースでは、編集権限リクエストは行わない。
- 編集者がチャートを開いている間に編集者削除された場合、次回自動保存時に保存エラーを表示し、ゲスト閲覧状態へ戻す。

### 6.5 マンダラチャート編集

- チャートは9x9の固定構造を持つ。
- 中央セルにメインテーマを入力できる。
- 中央周囲8セルに主要要素を入力できる。
- 各主要要素に対応する周辺8セルを入力できる。
- 各セルにはテキストのみ入力できる。
- セル内URL有効化は初期リリースでは行わない。
- セル編集内容はフォーカスアウト時に自動保存する。
- 自動保存時の更新時刻はサーバー時刻を基準とする。
- 保存時の更新反映で十分とし、リアルタイム同時編集は対象外とする。
- 複数人が同じセルを編集して競合した場合は、保存時間が遅い更新を採用する。
- 後勝ち保存で上書きされた内容は、初期リリースでは復旧できない。
- チャート作成者とチャート編集者は、対象チャートを編集できる。
- 初期リリースでは、セル色変更、完了状態、担当者メンション、期限、添付ファイルは対象外とする。

### 6.6 ゲスト閲覧

- 招待リンクを知っているユーザーは、ログインせずに対象チャートを閲覧できる。
- ログイン済みユーザーでも、招待リンクからの初期アクセス時はゲスト閲覧として扱う。
- ゲスト閲覧者はチャートを編集できない。
- ゲスト閲覧者は画像出力・PDF出力を利用できない。

## 7. 画面要件

### 7.1 認証画面

- Googleログインボタンを表示する。
- Googleログイン失敗時はエラーメッセージと再試行導線を表示する。
- 未ログインユーザーが認証必須機能を利用しようとした場合、ログイン画面へ誘導する。
- 初期リリースでは、新規登録フォーム、メールアドレス・パスワードログインフォーム、パスワード再設定フォームは表示しない。

### 7.2 チャート一覧画面

- 自分が作成したチャート一覧のみを表示する。
- チャートを作成できる。
- 作成チャート数が上限に達している場合、新規作成できないことを表示する。
- チャートのタイトル、作成者、最終更新日時を表示する。
- チャート作成者は、チャートを選択して閲覧・編集画面へ遷移できる。
- チャート作成者は、チャートタイトルを編集できる。
- 編集者として許可されたチャートは、チャート一覧には表示しない。
- チャート作成者は、自分が作成したチャートを削除できる。
- チャート削除時は確認ダイアログを表示する。
- チャート削除に成功した場合、削除済みであることを表示する。
- チャート削除に失敗した場合、エラーメッセージを表示する。

### 7.3 チャート共有設定画面

- チャートタイトルを表示する。
- 招待リンクの未発行・発行済み状態を表示する。
- 招待リンクを発行・確認・コピーできる。
- 招待リンクのコピーに成功した場合、コピー済みであることを表示する。
- 招待リンクのコピーに失敗した場合、手動コピーできるようリンク文字列を表示する。
- 編集許可済みメールアドレス一覧を表示する。
- チャート作成者はメールアドレスを指定して編集者を追加できる。
- チャート作成者は編集者を削除できる。
- 編集者数が上限に達している場合、追加できないことを表示する。
- 編集者追加に失敗した場合、エラーメッセージを表示する。
- 編集者削除に失敗した場合、エラーメッセージを表示する。

### 7.4 チャート閲覧・編集画面

- 9x9マンダラチャートを表示する。
- チャート作成者が一覧から開いた場合は、編集可能状態で表示する。
- チャート作成者は、チャートタイトルを編集できる。
- 招待リンク経由の初期アクセス時はゲスト閲覧状態で表示する。
- ゲスト閲覧状態では編集操作を無効化する。
- ゲスト閲覧者が編集アクションを行おうとした場合、Googleログインを求める。
- ログイン後に編集権限がある場合、セルを選択してテキスト編集できる。
- ログイン後に編集権限がない場合、編集できない旨を表示する。
- 許可メールアドレスとログイン中Googleアカウントのメールアドレスが一致しない場合、一致するGoogleアカウントでログインする必要がある旨を表示する。
- 編集権限がある場合、フォーカスアウト時に編集内容を自動保存する。
- 編集権限がある場合、保存状態を表示する。
- 自動保存に成功した場合、保存済みであることを表示する。
- 自動保存に失敗した場合、エラーメッセージを表示する。
- 編集者削除により保存権限がなくなった場合、保存エラーを表示し、ゲスト閲覧状態へ戻す。
- チャートタイトルを表示する。
- チャート作成者は共有設定画面へ遷移できる。
- チャート作成者はチャート一覧へ戻れる。

### 7.5 スマートフォン表示

- スマートフォンではチャート閲覧を中心とする。
- スマートフォンでの編集最適化は初期リリース対象外とする。
- スマートフォンでは9x9チャートを閲覧できる表示を優先する。
- スマートフォンで編集操作が困難な場合、PCまたはタブレットでの編集を促す表示を行う。

## 9. 非機能要件

### 9.1 対応環境

- 最新の主要ブラウザに対応する。
  - Google Chrome
  - Microsoft Edge
  - Safari
  - Firefox
- PC・タブレットでは閲覧・編集に対応する。
- スマートフォンでは閲覧中心の基本利用に対応する。
- UI言語は日本語のみとする。

### 9.2 パフォーマンス

- チャート一覧は通常利用範囲で3秒以内に表示する。
- チャート閲覧・編集画面は通常利用範囲で3秒以内に初期表示する。
- セル編集操作は体感上遅延が少ない状態を維持する。
- フォーカスアウト時の自動保存は通常利用範囲で速やかに完了する。

### 9.3 セキュリティ

- チャート作成者以外のユーザーは、チャート一覧から対象チャートを閲覧できない。
- 招待リンクを知っているユーザーは、対象チャートをゲストとして閲覧できる。
- チャート作成者またはチャート編集者以外のユーザーは、対象チャートを編集できない。
- チャート削除はチャート作成者のみ実行できる。
- Googleログインの認証結果をサーバー側または信頼できる認証基盤で検証する。
- 通信はHTTPSを前提とする。
- 入力値の検証を行い、XSSなどの基本的な脆弱性を防止する。
- 招待リンクトークンは推測困難な値を使用する。
- 編集権限はログイン中ユーザーのメールアドレスと編集許可メールアドレスで判定する。
- 初期リリースでは、招待リンクを知っていれば誰でも閲覧できるため、機密情報の入力は想定しない。

### 9.4 可用性・データ保護

- 保存済みのチャート、セル、共有設定が意図せず消失しないこと。
- 自動保存に失敗した場合はユーザーにエラーを表示する。
- 編集者削除により保存権限がなくなった場合、保存エラーを表示し、ゲスト閲覧状態へ戻す。
- 自動保存時の更新時刻はサーバー時刻を基準とする。
- 競合時は保存時間が遅い更新を採用する。
- 後勝ち保存で上書きされた内容は、初期リリースでは復旧できない。

### 9.5 アクセシビリティ

- キーボード操作で主要機能を利用できる。
- 入力フォームには適切なラベルを付与する。
- チャートセルは視認しやすいコントラストを確保する。

## 11. 想定ユースケース

### 11.1 個人利用としてチャートを作成・編集する

1. ユーザーがGoogleアカウントでログインする。
2. ユーザーがマンダラチャートを作成する。
3. 9x9分の81セルが初期作成される。
4. 初期作成に時間がかかる場合はローディング表示が表示される。
5. ユーザーがチャート一覧から自分のチャートを開く。
6. 必要に応じてチャートタイトルを編集する。
7. セルを編集する。
8. セルからフォーカスアウトする。
9. 編集内容が自動保存される。

### 11.2 チャートを作成して招待リンクを共有する

1. ユーザーがGoogleアカウントでログインする。
2. ユーザーがマンダラチャートを作成する。
3. チャート作成者が招待リンクを発行する。
4. チャート作成者が招待リンクをコピーする。
5. コピー済み表示を確認する。
6. チャート作成者が招待リンクを共有する。
7. 招待リンクを開いたユーザーは、ログイン状態にかかわらずゲストとしてチャートを閲覧する。

### 11.3 編集許可済みユーザーが招待リンクから編集する

1. チャート作成者が編集を許可するメールアドレスを登録する。
2. ユーザーが招待リンクからチャートを開く。
3. 初期状態ではゲストとしてチャートを閲覧する。
4. ユーザーが編集アクションを行う。
5. 未ログインの場合はGoogleログインを求められる。
6. ログイン中ユーザーのメールアドレスが編集許可済みであれば、編集を開始できる。
7. セルを編集する。
8. セルからフォーカスアウトする。
9. 編集内容が自動保存される。

### 11.4 権限がないユーザーが編集できないことを確認する

1. ユーザーが招待リンクからチャートを開く。
2. ユーザーが編集アクションを行う。
3. 未ログインの場合はGoogleログインする。
4. 編集権限がない場合、編集できない旨が表示される。
5. 編集権限リクエストは送信できない。

### 11.5 編集者を削除する

1. チャート作成者が共有設定画面を開く。
2. 編集許可済みメールアドレス一覧を確認する。
3. 不要になった編集者を削除する。
4. 削除されたユーザーは、次回自動保存時に保存エラーが表示され、ゲスト閲覧状態へ戻される。

### 11.6 チャートを削除する

1. チャート作成者がチャート一覧画面を開く。
2. 削除したいチャートを選択する。
3. 削除操作を実行する。
4. 確認ダイアログで削除を確定する。
5. チャートは論理削除される。
6. チャートが一覧から非表示になる。
7. 削除されたチャートは招待リンクから閲覧できない。

## 12. 制約・前提

- Webアプリとして提供する。
- 初期リリースでは日本語UIのみを対象とする。
- 初期リリースでは1チャートあたり9x9固定のマンダラチャートを前提とする。
- 初期リリースではグループ登録・グループ管理を行わない。
- 初期リリースではGoogleログインのみを対象とし、メールアドレス・パスワード認証とパスワード再設定は行わない。
- チャート作成はログイン済みユーザーのみ行える。
- チャート作成時に9x9分の81セルを初期作成し、時間がかかる場合はローディング表示を行う。
- チャート作成者は、作成後にチャートタイトルを編集できる。
- チャート削除は論理削除とし、削除済み状態として一覧および招待リンクから非表示にする。
- チャート一覧には自分が作成したチャートのみ表示する。
- チャート作成者のみ、一覧画面から自分のチャートを開ける。
- チャート作成者は、招待リンクを発行する前でも一覧画面から自分のチャートを閲覧・編集できる。
- チャート編集者とゲスト閲覧者は、招待リンクからのみ対象チャートを開く。
- 招待リンク経由の初期アクセス時は、ログイン済み・未ログインにかかわらずゲスト閲覧として扱う。
- 初期リリースでは招待リンクの有効期限、無効化、再発行は考慮しない。
- 招待リンクを知っていれば誰でも閲覧できるため、初期リリースでは機密性の高い情報を入力しない前提とする。
- 初期リリースでは編集権限リクエストを行わず、作成者によるメールアドレス登録のみで編集権限を付与する。
- セル入力内容はテキストのみとし、セル内URL有効化は行わない。
- 初期リリースでは通知機能、コメント機能、更新履歴は対象外とする。
- 初期リリースでは担当者メンション、画像出力、PDF出力は対象外とする。
- 初期リリースではスマートフォンでの編集最適化は行わず、閲覧中心とする。
- 初期リリースでは高度な同時編集は対象外とし、保存時の更新反映で十分とする。
- 自動保存はフォーカスアウト時に行う。
- 自動保存時の更新時刻はサーバー時刻を基準とする。
- 後勝ち保存で上書きされた内容は、初期リリースでは復旧できない。
- 利用開始時点では課金、プラン制限、利用量制限は考慮しない。
- 実装技術、ホスティング先、認証基盤は未定とする。
