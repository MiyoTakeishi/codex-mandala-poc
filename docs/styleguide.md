# UI Style Guide

このアプリは、目標設定や自己管理に使うマンダラチャートを、落ち着いて継続的に扱える道具として設計する。

## デザイン方針

- 白基調で余白を広めに取り、思考を整理しやすい静かな画面にする。
- 黒ではなく深いインク色を使い、強すぎないコントラストにする。
- アクセントは深いティールと控えめなアンバーに絞り、スタイリッシュで繊細な印象にする。
- 装飾は控えめにし、カード、フォーム、チャートの情報密度を優先する。
- 角丸は小さめに留め、ビジネスツールとしての緊張感と精度を保つ。

## カラートークン

- Background: `#F7F7F4`
- Surface: `#FFFFFB`
- Surface muted: `#F1F1EC`
- Text primary: `#18211F`
- Text secondary: `#66736D`
- Border: `#D8DAD2`
- Primary: `#1F5F58`
- Primary dark: `#173F3B`
- Accent: `#B8873D`
- Focus: `#1F6F65`

## UIルール

- 主要CTAはティール系、補助操作はアウトライン、危険操作は赤系を使う。
- カードは白に近い背景、薄いニュートラルグレーの枠線、最小限の影で統一する。
- 入力欄は白背景、ウォームグレーの枠線、フォーカス時にティールのリングを表示する。
- ページ見出しは短く、説明文は必要最小限にする。
- チャートのテーマカラーは維持しつつ、背景は淡く、枠線と中心セルで意味を出す。
